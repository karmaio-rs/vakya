## [0.1.0-alpha.1] - 2026-09-18

### Added

- Completion-native HTTP/1 client and server connection building blocks for the Karmaio runtime with Owned-buffer streaming bodies.
- Optional Karmaio Rustls integration with ALPN validation, TLS metadata, encrypted handoff, and application-owned provider and trust configuration.
